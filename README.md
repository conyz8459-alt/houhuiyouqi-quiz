# 测测你是《后会友期》里的谁

[打开测试网站](https://conyz8459-alt.github.io/houhuiyouqi-quiz/)

一份关于友情的非官方趣味测试，适配手机和电脑。12 道情境题，选择后自动进入下一题，生成八种嘉宾风格的友情解析。

- 保存个人结果海报或复制完整解析。
- 选择朋友的角色，查看双人相处建议。
- 进度保存在当前浏览器，不上传答案。

## 本地使用

在项目目录执行 `python -m http.server 8000`，浏览器打开 http://127.0.0.1:8000/ 即可预览。页面与 `assets/` 图片目录需要一起使用，无需安装前端依赖。

## 更新网站

网站由 GitHub Pages 从 `main` 分支根目录发布。修改文件后提交并推送到 `main`，等待 Pages 部署完成即可。

详细功能及编辑方式见 [使用说明](使用说明.md)，图片出处见 [图片来源](图片来源.md)。

本作品为非官方娱乐测试，不能代替心理测评；图片归原权利人所有。
